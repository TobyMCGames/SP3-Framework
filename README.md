NYP Studio Project 3:

Title: Timeless Hero
Platform: Desktop
Genre: 2D Roleplaying Game

How to download:
1) You can fork this repo, open it with Visual Studio and Run
2) Or download the .exe at https://hideinkopi.itch.io/the-timeless-hero

How to Play:
Movement:    WASD
Jump:        Spacebar
Pick Up:     E
Slow time:   Shift
Time Travel: Caps
Shoot:       Left Click
Change Item: Scroll
